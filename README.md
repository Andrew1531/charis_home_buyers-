# Charis Home Buyers

Source for the Charis Home Buyers website.

## Run locally

This project uses Vite and pnpm. From the repository root:

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm dev
```

Then open http://localhost:5173.

To create a production build:

```bash
PORT=5173 BASE_PATH=/ pnpm build
```
